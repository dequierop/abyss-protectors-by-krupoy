# Abyss Protectors by Krupoy

พัฒนาโดย ครูภัทรกันย์ กิติยศ

**ภารกิจพิทักษ์ทะเล** — เกมดำน้ำเก็บขยะและฝึกจำแนกพอลิเมอร์ สำหรับเล่นบนเว็บเบราว์เซอร์

## เปิดเล่น

เปิด `index.html` หรือเผยแพร่ด้วย GitHub Pages ได้เลย เกมโหลดฟอนต์ Mali จาก Google Fonts จึงต้องเชื่อมต่ออินเทอร์เน็ตเพื่อแสดงฟอนต์ดังกล่าว

## อัปโหลดขึ้น GitHub

1. แตกไฟล์ ZIP ลงในเครื่อง
2. อัปโหลด `index.html`, โฟลเดอร์ `assets/` และ `README.md` ไปไว้ที่รากของ repository
3. ใน GitHub ไปที่ **Settings → Pages** แล้วเลือก branch `main` และโฟลเดอร์ `/ (root)`
4. เปิดลิงก์ GitHub Pages ที่ GitHub แสดงให้

## การควบคุม

- คอมพิวเตอร์: ใช้ WASD หรือปุ่มลูกศรเพื่อว่ายน้ำ คลิกหรือกด Space เพื่อยิง
- จอสัมผัส: ใช้จอยสติกซ้ายเพื่อว่าย และปุ่มขวาเพื่อยิง
- เก็บขยะโดยว่ายชนสิ่งของ แล้วกลับขึ้นผิวน้ำเพื่อแยกประเภท

เสียงเพลงและเอฟเฟกต์จะเริ่มทำงานหลังจากกดปุ่มบนหน้าเกม ตามข้อกำหนดของเบราว์เซอร์
